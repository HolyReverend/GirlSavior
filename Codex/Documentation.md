# Documentation rules

| Location | Content | Language |
| --- | --- | --- |
| `Docs/GameDesign/` | Game rules, mechanics, and player experience | Plain Russian |
| `Docs/Technical/` | Implementation notes and technical decisions | Clear English with Unreal terms where helpful |
| `Codex/` | Codex instructions and project context | Clear English with technical terms where helpful |

- Write short, focused Markdown files. Give each file one topic that an agent can read independently.
- Keep each rule or decision in one place. Link to it from related files when needed.
- Keep task routing in the workspace root `AGENTS.md`. Add a route when agents need a new document for a specific type of work.
