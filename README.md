# GirlSavior

GirlSavior — экшен-роглайт для взрослой аудитории (18+) в мире тёмного фэнтези. В бою игрок управляет движением и прицелом независимо, как в twin-stick shooter. Герой спускается в Бездну, подземелье между мирами, чтобы сражаться с чудовищами и спасать девушек, оказавшихся там.

Во время вылазок игрок выбирает маршрут, собирает ресурсы и получает временные усиления. В лагере у магического костра он развивает убежище, узнаёт истории спасённых героинь и готовится к следующей экспедиции.

Игра разрабатывается на **Unreal Engine 5.9** с использованием **C++**. В репозитории находятся [проект Unreal](GirlSavior/), [концепт игры](Docs/GameDesign/ConceptDesign.md) и [концепт-арты](Arts/README.md).
