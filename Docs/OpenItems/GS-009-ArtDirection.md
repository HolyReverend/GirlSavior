# GS-009 · Конкретизация художественного стиля

**Тема** — Графика

**Статус** — Открыто

## Что открыто

Первым ориентиром для Бездны стала мрачная диорама с лёгкой рисованной фактурой и детализацией моделей между low-poly и mid-poly. Появился первый концепт встречи с врагом с изометрического ракурса. Предстоит подобрать остальные референсы и сформулировать правила оценки игровых материалов. [Первый концепт Бездны](../../Arts/Visions/AbyssHallFirstEncounter-v1.png)

Для сравнения подготовлен второй вариант той же сцены в стиле рисованного тёмного фэнтези с аниме-чибиком. На нём можно оценить, как увеличенная голова и короткие пропорции влияют на читаемость героя, а более яркий свет Факела и цветные тени — на настроение Бездны. [Вариант с чибиком](../../Arts/Visions/AbyssHallFirstEncounter-Chibi-v1.png)

Для начала игры выбран вариант с базовым Факелом. Для Лагеря утверждены кадры первого розжига Костра и обжитой площадки после спасения героинь. [Начало игры](../../Arts/Visions/AbyssHallFirstEncounter-Chibi-TorchOnly-v1.png) · [Стартовый Лагерь](../../Arts/Visions/AbyssCamp-Starting-Chibi-v1.png) · [Обжитой Лагерь](../../Arts/Visions/AbyssCamp-Chibi-v1.png)

Рисованные концепт-листы базовых, дополнительных и элитных противников приняты как визуальные референсы. Предстоит проверить различимость силуэтов в игровом масштабе и при свете базового Факела. [Концепты обычных противников](../GameDesign/Mechanics/Encounters/EnemyTypes.md#концепты-внешности) · [Концепты и правила подачи элит](../GameDesign/Mechanics/Encounters/EliteEnemyPresentation.md)

Для главного героя, Лиоры, Иды и Сайры подготовлены отдельные концепт-листы в стиле обжитого Лагеря. Концепт Иды утверждён. У Лиоры и Сайры обновлена одежда на обоих ракурсах. [Главный герой](../GameDesign/Hero.md) · [Лиора](../GameDesign/Mechanics/Heroines/Liora.md) · [Ида](../GameDesign/Mechanics/Heroines/Ida.md) · [Сайра](../GameDesign/Mechanics/Heroines/Saira.md)

Для интерфейса Лагеря предложены тёмные панели и цветовые акценты у портретов. Первый эскиз показывает вкладку «Истории» на фоне обжитого Лагеря. [Эскиз интерфейса](../../Arts/Visions/CampStories-Interface-v1.png)

Для визуальной новеллы подготовлен первый полнофигурный концепт главного героя в современной аниме-стилистике со взрослыми пропорциями. Предстоит оценить образ и читаемость персонажа на фоне Лагеря. [Концепт героя для визуальной новеллы](../../Arts/Characters/MainHero-VisualNovel-v1.png)

Для Лиоры подготовлен первый концепт для визуальной новеллы в полный рост на прозрачном фоне. За основу взят обновлённый облик Лиоры, за ориентир по стилю — концепт главного героя для диалогов. Предстоит оценить образ и читаемость в сцене Лагеря. [Концепт Лиоры для визуальной новеллы](../../Arts/Characters/Heroines/Liora-VisualNovel-v1.png)

На основе утверждённого образа Иды подготовлен первый концепт в полный рост для визуальной новеллы. Читаемость Иды на фоне Лагеря предстоит проверить в диалоге. [Концепт Иды для визуальной новеллы](../../Arts/Characters/Heroines/Ida-VisualNovel-v1.png)

На основе обновлённого образа Сайры подготовлен первый концепт в полный рост для визуальной новеллы. Читаемость Сайры на фоне Лагеря предстоит проверить в диалоге. [Концепт Сайры для визуальной новеллы](../../Arts/Characters/Heroines/Saira-VisualNovel-v1.png)

Для иллюстраций визуальной новеллы зафиксированы референсы, правила отрисовки и критерии проверки. Предстоит сравнить спрайты в масштабе диалога на фоне Лагеря с панелью реплики и ответами. [Стиль иллюстраций визуальной новеллы](../GameDesign/VisualNovelArtStyle.md)

## Условие закрытия

При подготовке художественного задания выбрать конкретные референсы и закрепить правила, по которым можно оценить первый набор игровых материалов.
