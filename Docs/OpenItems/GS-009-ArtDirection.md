# GS-009 · Конкретизация художественного стиля

**Тема** — Графика

**Статус** — Открыто

## Что открыто

Текущий документ задаёт стилизованную 3D-подачу экспедиций и 2D-подачу личных историй. Детали стиля остаются открытыми.

## Условие закрытия

При подготовке художественного задания выбрать конкретные референсы и закрепить правила, по которым можно оценить первый набор игровых материалов.
