# GS-012 · Автоматическое исчезновение снаряда

**Тема** — Unreal / стрельба

**Статус** — К проверке

## Что открыто

На этапе 4 проверили настройку времени жизни тестового снаряда. Автоматическое исчезновение по истечении этого времени в запуске не наблюдали.

## Условие закрытия

В задаче на проверку снарядов запустить снаряд без столкновений и подтвердить, что он исчезает по истечении заданного времени. Занести наблюдение в техническую запись.
