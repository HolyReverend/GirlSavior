# GS-004 · Условия успешной эвакуации

**Тема** — Спасение

**Статус** — Закрыто

## Решение

Для первого сценария описаны запуск испытания, зарядка портала, успех и провал. Спасение закрепляется в момент эвакуации при живом герое. После возвращения в убежище героиня доступна игроку, даже если герой погиб после её эвакуации. Провал до этого момента позволяет повторить вылазку с нулевым прогрессом.
