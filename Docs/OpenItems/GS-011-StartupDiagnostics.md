# GS-011 · Предупреждения и ошибки при запуске

**Тема** — Unreal / диагностика

**Статус** — К проверке

## Что открыто

В технических записях зафиксированы две стартовые диагностики Condition failed и предупреждение о viewport CommonUI. Они оставались открытыми после проверки стрельбы 8 ноября.

19 ноября 2026 года на UE 5.9 Preview 1 обе строки `LogAutomationTest: Error: Condition failed` снова появились при запуске. Редактор открыл Demo, карта запустилась в PIE, и все 11 выбранных автотестов прошли. Сообщение о viewport CommonUI в журнале этого запуска PIE не появилось. Источник двух стартовых сообщений пока не определён.

После обновления UE 5.9 до сборки CL 60738873 обычное открытие проекта показало два окна. `Target Upgrade Required` относилось к настройкам V7 у цели Editor. `Missing GirlSavior Modules` появилось из-за того, что модули GirlSavior и PinWright были собраны для CL 60351404. После перехода цели Editor на V8 и пересборки под CL 60738873 файл `.uproject` снова открывает Demo через Windows без этих окон. Две строки `Condition failed` остались в журнале запуска.

При пробе Epic MCP на той же сборке редактор открыл Demo с отключённым PinWright. Две строки `Condition failed` повторились. Оба автотеста GirlSavior прошли, и PIE запустил Demo с одним персонажем.

21 ноября 2026 года при проверке CP0 обе строки снова появились до запуска тестов GirlSavior. Demo открылся и запустился в отдельном окне PIE. Источник сообщений ещё предстоит определить.

24 ноября 2026 года после ревью игрового C++ обе строки снова появились при запуске редактора. Все 15 автотестов `GirlSavior.` завершились успешно. Все четыре карты открылись после переименования Blueprint, проверка Map Check на каждой дала 0 ошибок и 0 предупреждений.

## Условие закрытия

При задаче на диагностику запуска проверить свежий лог. Если сообщения повторяются, определить их источник и влияние. Записать исправление либо объяснение, почему сообщение можно оставить.
