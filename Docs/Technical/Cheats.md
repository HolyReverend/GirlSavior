# Gameplay cheats

Open the Unreal console with the Tilde key during PIE or in a Development build. Enter the command without arguments. This list covers GirlSavior gameplay cheats.

| Command | Effect | Where to use it |
| --- | --- | --- |
| `sv_giveallweapon` | Fills empty expedition slots with the weapons missing from the current set. From a fresh start, slots 1–3 hold the pistol, shotgun and assault rifle. | In a local combat expedition with a living hero, including its safe starting area. |

Use `1`–`3` to select the granted weapons. The command keeps existing slot assignments, the active weapon and the current cooldown. If the slots already contain all weapons, entering the command again leaves the set as it is.

The grant lasts for the current expedition. The confirmed Camp loadout and weapon unlocks are stored separately. Shipping builds omit the command.
