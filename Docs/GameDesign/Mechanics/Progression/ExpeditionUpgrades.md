# Усиления в экспедиции

Во время вылазки игрок может усилить основное оружие, изменить эффекты активных способностей выбранных героинь и получить временные пассивные бонусы. Эти эффекты можно сочетать, чтобы менять боевой билд по ходу маршрута.

Усиления действуют до конца текущей экспедиции. Собственные бонусы героя используют остаток общего бюджета силы вместе с постоянными улучшениями. Эффекты способностей героинь относятся к поддержке.
