# Героини

Порядок первых спасений — Лиора, Ида, Сайра. Все три героини взрослые. Происхождение, образ, способности и ранги хранятся в карточках. [Занятия в лагере](../Camp/CampHub.md#роли-героинь) · [Состав поддержки и прокачка](HeroineSupport.md)

| Героиня | Роль поддержки |
| --- | --- |
| [Лиора](Liora.md), грозовая проводница | Контроль движения врагов |
| [Ида](Ida.md), инженер-рунница | Поддержка огнём |
| [Сайра](Saira.md), храмовая хранительница | Защита под давлением |

## Сочетания героинь

- **Лиора + Ида.** Замедление даёт турели больше времени стрелять по плотной группе.
- **Лиора + Сайра.** При защите эвакуации замедление помогает держать дистанцию у цели, а барьер прикрывает отход.
- **Ида + Сайра.** Поддерживают огонь и помогают пережить ответную атаку на средней дистанции.
