# Возвращение из экспедиции

По предварительной модели герой сохраняет собранную добычу при выходе через точку возврата. При гибели он возвращается в убежище и теряет часть ресурсов, которые ещё не успел вынести. Закреплённые спасения обрабатываются по [правилам эвакуации](HeroineRescue.md).
