# Усиления в экспедиции

Во время вылазки игрок может усилить основное оружие, изменить эффекты активных способностей героинь и получить временные пассивные бонусы. Эти эффекты можно сочетать, чтобы менять боевой билд по ходу маршрута.

Усиления действуют до конца текущей экспедиции. Постоянные открытия описаны в [развитии убежища](ShelterDevelopment.md).
