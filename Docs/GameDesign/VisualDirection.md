# Визуальное направление

В экспедициях используются трёхмерные стилизованные low-poly модели, модульные декорации и выразительные силуэты. По силуэту игрок должен различать героя, врагов и интерактивные объекты с [игрового ракурса](Mechanics/Player/GameCamera.md). Снаряды, предупреждения об атаках и эффекты способностей должны оставаться различимыми, когда несколько эффектов появляются одновременно.

Диалоги, личные истории и романтические события используют приёмы визуальной новеллы. Для них предполагаются 2D-портреты с вариантами выражений, иллюстрации и отдельные CG. Общий лист референсов для каждой героини поможет сохранять её облик на разных изображениях. GPT Image и локальный ComfyUI рассматриваются как инструменты для подготовки этих материалов.

Образы первых героинь опираются на разные миры и магию. Портреты различаются по силуэту и реквизиту. В бою молния, руны и защитные печати должны различаться по форме и звуку. [Каталог героинь](Mechanics/Heroines/Heroines.md)
