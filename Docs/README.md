# Project documentation

Choose the branch that answers the task. Open only the files you need within that branch.

| What you need | Where to look |
| --- | --- |
| What the game is and how it plays. Concepts, mechanics, game rules, and player experience. | [GameDesign](GameDesign/) |
| How the project will be built. Roadmap, implementation stages, technical architecture, and implementation notes. | [Technical](Technical/) |

For a technical task, start in `Technical/`. Open a specific document in `GameDesign/` only when the task also needs a gameplay rule or other design decision. For a game design task, start in `GameDesign/` and open technical material only when you need a technical constraint.
