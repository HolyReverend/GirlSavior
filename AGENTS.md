# GirlSavior

Develop GirlSavior through vibe coding with Codex.

- [GirlSavior/](GirlSavior/) contains the Unreal project.
- [Docs/](Docs/) contains game design and technical documentation.
- [Codex/](Codex/) contains detailed instructions and project context for Codex.

Before starting a task, choose the route that matches the work. If the target document is already known, open it directly. Read each required file once and reuse it during the task. Links are references; follow them only when the task needs their contents. Search within the relevant area and exclude report folders under the report access rules.

When progress requires a user answer, decision, or manual check, promptly ask a direct question in the chat with concise answer options. Do not remain silently thinking or waiting for unrequested user action. State what is needed and why. Continue independent authorized work while waiting, but leave dependent work pending until the user answers; do not treat silence as confirmation or claim an unperformed check passed.

At the end of every task, create the required [work reports](Codex/WorkReports.md). Follow the access rules in that guide when reading or searching reports.
