Develop GirlSavior through vibe coding with Codex.

Before starting a task, use the matching route below. If you know the target document, open it directly and read the relevant section. Reuse the context already loaded. Follow links when you need the referenced rule or evidence. Limit searches to the relevant area and exclude [work reports](Codex/WorkReports.md) during routine searches.

For work that touches a project system, check the matching topic in the [open-item index](Docs/OpenItems/Index.md). If the task names a card, open it directly. Read a card when it can affect the task through a decision, risk, or check. Record material findings and update affected cards using the [open-item workflow](Codex/OpenItems.md).

When progress requires a user answer, decision, or manual check, promptly ask a direct question in the chat with concise answer options. Do not remain silently thinking or waiting for unrequested user action. State what is needed and why. Continue independent authorized work while waiting, but leave dependent work pending until the user answers; do not treat silence as confirmation or claim an unperformed check passed.

At the end of every task, create the required [work reports](Codex/WorkReports.md). Follow the access rules in that guide when reading or searching reports.
