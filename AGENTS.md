# GirlSavior

Develop GirlSavior through vibe coding with Codex on Unreal Engine 5.8.4. Prefer C++ for gameplay and use a data-driven approach.

- [GirlSavior/](GirlSavior/) contains the Unreal project.
- [Docs/](Docs/) contains game design and technical documentation.
- [Codex/](Codex/) contains detailed instructions and project context for Codex.

Before starting a task, read only the rules and project documents needed for it. Use the table to choose what to open. Follow additional links only when the task requires them.

Open the Unreal skill guide only when the task requires direct work on Unreal code, assets, configuration, builds, tests, or the editor. Skip it for game design, documentation, and Codex workflow tasks that do not require such work.

At the end of every task, create the required [work reports](Codex/WorkReports.md). Follow the access rules in that guide when reading or searching reports.
